# Treatment · 打样纸

30 s / 1920×1080 / 112 BPM / 14 bars = exactly 30.00 s / no narration / 片尾不带签名（用户要求去掉）。

**The one thing**: 14 个 8K 竖屏视频，从文件夹拖进软件，12.5 秒变成一整面封面墙，而且一个字节都没上传。

Language: desktop-as-stage + card-montage。两个窗口（文件夹、软件）就是世界，镜头只在它们之间推、停、切，
后面接的样张墙是同一件事的结果。Look: 产品的纸灰白、白窗帘、Noto Sans SC 黑体、Inter 表格数字、一支蓝。
没有 3D、没有发光、没有渐变网格。

## Route

Hybrid。一条连续的故事线：文件夹 → 框选 → 拖 → 放进软件 → 逐格出图 → 样张纸，中间一个蒙太奇爆发（放大镜连切）和一次停顿。

## Four stills

- **Hook 0.5 s** — 一支 1600 px 宽的 Windows 文件夹，七列两行真实缩略图；文件名是 `30 fps - Seedance 2_5 - …4K_2.00x_6144x8192_ahq-11.mp4`，每格右下角是 `00:05.0` 与 `513 MB · 10.0s`。
- **Hero 5.6 s** — 软件铺满画面，14 张卡刚落下，蓝色 `▶ 开始批量截图` 在左下角。
- **Densest 7.4 s** — 逐格出图：绿章连成一片，蓝色扫描线正扫到第二排。
- **End 26.5 s** — 纸面、logo、`视频批量截图`。

## Continuity chain

一支文件夹 → 同样那 14 张缩略图被拖走 → 同一批缩略图落进软件的列表 → 同一批图逐格变成「已截图」→
同一批图铺成样张纸 → 样张里的一张被放大到 8K → 缩回整墙 → 软件带着绿勾回场 → 清成纸面 → logo。

每一段之间都有一件东西被带着走（那 14 张图、那支蓝、那个 12.5）。没有一处是「换一页」。

## 与上一版的不同

上一版开场是「14 张黑卡的墙 + 3.4× 拉开」。用户看后要求改成真实动作：文件从文件夹拖进软件，要有拖拽和添加的过程。
这一版把软件界面在代码里重建（左侧设置栏、顶栏计数、底部进度、每张卡的角标），所以 14 张卡能真的一张张落进去、
角标能一张张翻绿——贴截图做不到这件事。样张墙里也不再出现「黑卡翻面」，14 张图一上来就是彩色的。

## Sound

国风电子与极简脉冲的交界：古筝/马林的十六分音符当机械脉搏，低弦长音铺底，电影鼓组给落点，
主题动机（A–C–E–D）在落的时候由马林 + 低弦加倍。A 小调，i–VI–III–VII。
停的那 1.9 秒什么都不留。57 个音效落点，全部对在画面上。
