## 这个版本有什么

- **桌面程序**：双击直接开窗口，不再借浏览器。Electron 的 `webUtils.getPathForFile()` 拿到拖入文件的真实路径，拖拽导入才真正可用。
- **本地解码**：视频按路径交给 ffmpeg，不复制、不上传、不改原片。8K 竖屏原片直接出帧。
- **批量取帧**：中间帧（默认）/ 首帧 / 百分比 / 固定秒，四种取帧方式可以混用。
- **自动跳过黑场**：中间帧偏黑时自动换时间点重试，避免导出纯黑图。
- **单张调帧**：点某张卡的「调整」，拖滑块看大图定帧，重新出这一张，不动其他。
- **同名覆盖**：重跑不堆 `(2)(3)` 副本，也可切成自动加序号另存。
- **并发可调**：1–6，机械盘往低调，SSD 可以调高。

## 性能

14 个 8K 竖屏视频（4992×6656 到 6144×8192，合计 8.6 GB），并发 3，全量出图 **12.5 秒**。

## 已知问题

- 安装包未做代码签名，Windows SmartScreen 首次运行会提示「未知发布者」，点「更多信息 → 仍要运行」即可。
- 原片自带黑边时，导出图会保留黑边。
