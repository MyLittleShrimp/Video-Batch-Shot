# 安装包打包说明（v1.1.0 桌面版）

产物：`dist\视频批量截图工具_v1.1.0_安装包.exe`（约 119 MB，内容 401 MB，压缩率 31%）

## 架构变了

v1.0.x 是「Node 服务 + 浏览器界面」，v1.1.0 改成 **Electron 桌面程序**：

```
视频批量截图工具.exe        ← 入口，双击直接开窗口
resources\app\
  ├─ main.js               主进程：找空闲端口 → 起 server.js → 开窗口
  ├─ preload.js            只暴露一个能力：拿拖入文件的真实路径
  ├─ server.js             本地服务（和网页版共用同一份代码）
  ├─ app\                  界面（html/css/js）
  └─ bin\ffmpeg.exe        内置解码器
```

**为什么要套壳**：浏览器出于安全不给 File 对象的本地路径，而本工具是「ffmpeg 按路径读本地文件、不上传」的设计，
网页版天然做不到拖拽导入（硬要做得先把文件读进内存再传到本地服务，等于复制一遍）。
Electron 的 `webUtils.getPathForFile(file)` 能拿到真实路径，拖拽才真正可用。
顺带解决的：不用再开浏览器窗口、有独立任务栏图标、单实例（重复双击只激活已有窗口）。

关键点：
- 主进程用 `spawn(process.execPath, [server.js], { env: { ELECTRON_RUN_AS_NODE: '1' } })` 起服务，
  即用 Electron 自带的 Node 跑 server.js，不需要外挂 node.exe（省 95 MB）。
- 端口从 7788 起自动找空闲的，找到后把 PORT 传给子进程；窗口加载 `http://127.0.0.1:<port>/`。
- 子进程 `NO_OPEN=1`，不会再去开浏览器。
- 单实例锁 `app.requestSingleInstanceLock()`，第二次启动只聚焦已有窗口。

## 打包步骤

### 1. 装依赖（只需一次）

```bash
cd desktop
ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ npm install
```

已锁 Electron **33.4.11**（`webUtils.getPathForFile` 需要 32+）。

### 2. 组装应用目录 `build/appsrc`

```bash
cd C:/Users/panda/WorkBuddy/视频批量截图工具
rm -rf build/appsrc && mkdir -p build/appsrc/bin
cp desktop/main.js desktop/preload.js build/appsrc/
cp server.js build/appsrc/
cp -r app build/appsrc/app
cp build/app.ico build/appsrc/icon.ico
cp build/app.ico build/appsrc/app.ico
cp "E:/Program Files/ffmpeg/bin/ffmpeg.exe" build/appsrc/bin/ffmpeg.exe
```

`build/appsrc/package.json`：

```json
{ "name": "video-batch-shot", "productName": "视频批量截图工具",
  "version": "1.1.0", "main": "main.js" }
```

### 3. 打 Electron 包

```bash
cd desktop
ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ \
node node_modules/electron-packager/bin/electron-packager.js \
  ../build/appsrc "视频批量截图工具" \
  --platform=win32 --arch=x64 --electron-version=33.4.11 \
  --icon=../build/app.ico --out=../build/pack --overwrite \
  --app-version=1.1.0 \
  --win32metadata.CompanyName="panda" \
  --win32metadata.FileDescription="视频批量截图工具" \
  --win32metadata.ProductName="视频批量截图工具"
```

输出 `build/pack/视频批量截图工具-win32-x64/`，约 401 MB（exe 189 MB + ffmpeg 137 MB + 其余）。
**不要开 asar**：保持散文件，server.js 读写 app\ 和 bin\ 的路径最直观，也方便现场改。

打完把 `使用说明.txt`（**GBK + CRLF**）拷进这个目录根，安装包会一起带上。

### 4. 编译安装包

```bash
cd build
./nsis/nsis-3.10/makensis.exe -V3 installer.nsi
```

约 2.5 分钟（401 MB 走 LZMA solid）。注意 Git Bash 里 `/V3` 会被当路径转义，必须用 `-V3`。

## 踩过的坑

1. **`ELECTRON_RUN_AS_NODE=1` 会污染环境**：本机 WorkBuddy 宿主环境里带这个变量，
   直接跑 `electron.exe` 会被当成纯 Node，报 `Cannot find module 'electron'`。
   自测启动要 `env -u ELECTRON_RUN_AS_NODE`。用户双击 exe 不受影响。
2. **拖拽必须全局 `preventDefault`**：否则浏览器把拖入文件当导航，开一堆窗口 / 跳走页面。
   在 `window` 上拦 `dragover` / `drop`，再单独处理蒙层与导入。
3. **文件名/路径含中文**：`.nsi` 必须 UTF-8 带 BOM；测试用 exe 要先复制成 ASCII 名再执行。
4. **升级要清旧文件**：安装前先 `RMDir /r` 掉 v1.0.x 的 `node\ bin\ app\`，否则 95 MB 的旧 node 会一直留着。
5. **卸载最后删不掉目录**：`Section "Uninstall"` 开头要 `SetOutPath "$TEMP"`，否则当前目录被占用，空文件夹残留。

## 已做的定制

1. **中文界面字体**：`SimpChinese.nlf` 从「宋体 9」改成「Microsoft YaHei UI 9」
   （`build/nsis/nsis-3.10/Contrib/Language files/`，原文件留 `.bak`，重解压 NSIS 需重做）。
2. **图标**：`build/icon.svg` → Chrome 无头渲染 256×256 → 缩成 16/32/48/64/128 合成 `app.ico`。

```bash
ffmpeg -i s16.png -i s32.png -i s48.png -i s64.png -i s128.png -i icon256.png \
  -map 0:v -map 1:v -map 2:v -map 3:v -map 4:v -map 5:v app.ico
```

3. **向导图片按控件实际像素出图**（关键）：

   MUI2 的欢迎图控件写的是 `109u × 193u`，**换像素取决于界面字体度量**。雅黑 9 号下实际是：

   | 图片 | 控件实际像素 | 文件 |
   |---|---|---|
   | 欢迎图 | **191 × 410** | `welcome.bmp` |
   | 头图 | **175 × 74** | `header.bmp` |

   按老尺寸出图会被非等比拉伸（图标锯齿、文字发糊）。出图必须 1:1 渲染，不要先画大再缩。
   另有 `ManifestDPIAware` + `System` 声明，高分屏不整窗拉伸。
